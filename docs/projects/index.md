# Project Guides

!!! WARNING "Refactor in progress - Winter 2026"
    Examples are taken from experiences over the last 15 years and much has changed in that time. Many guides have been refactored several times to keep up with changes, although there is much more work to do in this regard.

    Leiningen has been replaced by Clojure CLI (and Make) for running and building Clojure projects.

    Ring & Compojure libraries have been replaced by Reitit and Reitit.ring libraries for building web services with a data oriented design.

    Mulog has replaced all previous logging approaches.

    Creating and maintaining detailed guides is time consuming and there is a significant backlog of new guides to add. However, suggestions and contributions are most welcome.

Follow a step-by-step project guide and build a live services which can also be deployed.
